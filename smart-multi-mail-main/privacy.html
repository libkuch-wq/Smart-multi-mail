Smart Multi-Mail · poslední aktualizace 24. srpna 2026

Smart Multi-Mail je soukromá aplikace pro jednoho uživatele — jejího provozovatele. Nemá další uživatele, nenabízí registraci a nikomu neposkytuje žádná data.

Aplikace neběží na cizí infrastruktuře. Backend si provozuje uživatel sám na svém počítači. Data neprochází přes žádný server třetí strany.

K čemu aplikace přistupuje

Po přihlášení přes Google si vyžádá tato oprávnění:

  • gmail.readonly — čtení zpráv, aby je aplikace mohla zobrazit.
  • gmail.send — odeslání odpovědi, kterou uživatel sám napsal a potvrdil.
  • userinfo.email a openid — zjištění adresy připojeného účtu, aby ji aplikace uměla rozlišit od ostatních.

Aplikace nemůže mazat zprávy ani měnit nastavení účtu. Nepřistupuje k Disku, kontaktům, fotkám ani kalendáři.

Co se ukládá a co ne

Obsah e-mailů se neukládá. Zprávy zůstávají na serverech Googlu a aplikace je načítá z Gmail API až ve chvíli, kdy se na ně uživatel dívá.

Do lokální databáze se ukládá pouze:

  • přístupový (refresh) token ke každému připojenému účtu, šifrovaný algoritmem AES-256-GCM;
  • e-mailová adresa a jméno účtu, aby šlo rozlišit, odkud zpráva přišla;
  • barva přiřazená účtu a názvy skupin, které si uživatel vytvořil.

Databáze je soubor na počítači uživatele. Neopouští jeho zařízení a není zálohována nikam do cloudu.

Komu se data předávají

Nikomu. Aplikace neobsahuje reklamu, analytiku ani měřicí kódy. Nekomunikuje s žádnou službou kromě rozhraní Google, které je nutné pro její vlastní chod. Data se neprodávají, nesdílejí ani nepoužívají k trénování modelů.

Soulad s pravidly Google API

Nakládání s daty získanými z rozhraní Google API se řídí Google API Services User Data Policy včetně požadavků na omezené použití (Limited Use). Data z Gmailu slouží výhradně k zobrazení pošty a odeslání odpovědi v této aplikaci — k ničemu jinému.

Jak přístup odebrat

Účet lze kdykoli odpojit přímo v aplikaci; tím se smaže uložený token i metadata. Nezávisle na tom lze přístup odvolat na straně Googlu na stránce myaccount.google.com/permissions. V obou případech ztratí aplikace přístup okamžitě. V Gmailu se nic nesmaže.

Kontakt

Aplikaci provozuje jediná soukromá osoba pro vlastní potřebu. Kontaktní adresa je uvedena na souhlasné obrazovce Google, která se zobrazí při připojení účtu.
